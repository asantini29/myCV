%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
% Shared preamble for every document in this repository
% (cv/, cover_letter/, research_statement/).
%
% Input it right after \documentclass:
%
%     \input{../personalinfo}
%     \documentclass[11pt, a4paper]{awesome-cv}
%     \input{../preamble}
%
% \documentclass deliberately stays in each document: the options differ from
% one document to the next, and LaTeX Workshop locates a root file by looking
% for it. Anything else that differs per document (\geometry, \linespread,
% \thefootnote, the footer) also stays in the document itself.
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
